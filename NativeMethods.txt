// Lista auditable de P/Invokes. Todas son APIs publicas documentadas y actuan sobre el
// propio proceso o el propio HWND. Cada grupo lleva encima para que es: ahi es donde
// mira un auditor, y cada entrada tiene que poder senalarse a una seccion de
// SEGURIDAD.md §3.
//
// Crece un grupo por hito. Si una entrada no se puede senalar a una seccion, o sobra la
// entrada o falta la seccion.

// --- Consola estando compilado como WinExe (H0) ---
// Sin esto, --check y --buscar no tendrian donde escribir al lanzarse desde una terminal.
AttachConsole

// --- Inventario de aplicaciones (H1, SEGURIDAD.md §3.1) ---
// La misma carpeta virtual que enumera el menu Inicio para pintarse a si mismo. Se leen
// SOLO el nombre visible y el destino; no se abre ningun ejecutable ni se mira dentro de
// nada. IShellLink NO esta aqui a proposito: los .lnk se lanzan tal cual y el shell los
// resuelve, asi que ni su destino se lee.
SHCreateItemFromParsingName
IShellItem
IEnumShellItems
BHID_EnumItems
SIGDN

// --- Ventana propia (H4) ---
RegisterClassExW
CreateWindowExW
DefWindowProcW
DestroyWindow
PostQuitMessage
ShowWindow
SetWindowPos
GetModuleHandleW
LoadCursorW
IDC_ARROW
GetClientRect
GetWindowRect

// --- Bucle de mensajes propio (H4) ---
GetMessageW
TranslateMessage
DispatchMessageW

// --- Atajo de teclado (H4, SEGURIDAD.md §3.3) ---
// NO es un hook: no se observa el teclado, se le pide a Windows que mande WM_HOTKEY a
// NUESTRA ventana cuando se pulse UNA combinacion. Sin DLL en otros procesos y sin ver
// ninguna otra tecla. Es como registra su atajo cualquier app.
RegisterHotKey
UnregisterHotKey

// --- Ponerse delante, SOLO nosotros (H4, SEGURIDAD.md §3.4) ---
// La unica excepcion de la regla 15, y la que auditar.ps1 vigila aparte: el argumento
// es siempre _hwnd. Windows autoriza esto al proceso que acaba de recibir WM_HOTKEY;
// sin ello la ventana aparece sin foco y no recibe lo que escribes.
SetForegroundWindow
SetFocus

// --- La caja de texto, que es un control del sistema (H4, SEGURIDAD.md §3.2) ---
// El caret, la seleccion, las teclas muertas y Ctrl+V los hace el propio EDIT dentro
// del sistema. Nosotros solo le pedimos el texto con WM_GETTEXT y le ponemos la fuente.
// Por eso aqui no hay ni una API de portapapeles (regla 14).
SendMessageW
CreateFontIndirectW
DeleteObject
LOGFONTW
SystemParametersInfoW
NONCLIENTMETRICSW

// --- Donde ponerse y a que escala (H4, solo lectura) ---
// No se enumera ninguna ventana ni ningun proceso: solo se pregunta donde esta el
// monitor del cursor y a que escala, para colocarnos encima.
GetCursorPos
MonitorFromPoint
GetMonitorInfoW
GetDpiForMonitor

// --- Acrilico y esquinas redondas sobre la ventana propia (H4) ---
DwmSetWindowAttribute
DWMWINDOWATTRIBUTE

// --- Composition interop, sobre el HWND propio (H4) ---
// El puente Win32 -> Windows.UI.Composition.
ICompositorDesktopInterop
CreateDispatcherQueueController
DispatcherQueueOptions

// --- Superficie de dibujo propia: D3D11 -> D2D -> Composition (H4) ---
// Fuera de XAML no existe LoadedImageSurface, asi que para pintar texto hay que montar
// esta cadena. Actua solo sobre nuestras superficies; no lee la pantalla ni la ventana
// de nadie.
D3D11CreateDevice
D2D1CreateDevice
ID3D11Device
ID2D1Device
ID2D1DeviceContext
IDXGIDevice
D3D_DRIVER_TYPE
D3D11_CREATE_DEVICE_FLAG
D2D1_ALPHA_MODE
DXGI_FORMAT
ICompositorInterop
ICompositionDrawingSurfaceInterop

// --- Texto, sobre nuestra propia superficie de dibujo (H4) ---
DWriteCreateFactory

DWRITE_TEXT_METRICS

// --- Lanzar lo seleccionado (H4, SEGURIDAD.md §3.8) ---
// Es lo mismo que hace un doble clic: mismo API, mismo alcance, y siempre detras de un
// Enter tuyo sobre una fila que estas viendo. Nunca el verbo runas (regla 17).
ShellExecuteExW
SHELLEXECUTEINFOW

// --- La caja de texto en oscuro (H4) ---
// Un EDIT pinta su propio fondo con los colores del sistema, que en claro es blanco.
// WM_CTLCOLOREDIT es la forma documentada de decirle otros, y por eso la franja va en
// color solido y el acrilico empieza debajo.
CreateSolidBrush
SetTextColor
SetBkColor

ID2D1SolidColorBrush
D2D1_ROUNDED_RECT
