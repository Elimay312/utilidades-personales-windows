// Lista auditable de P/Invokes. Fichero de entrada de CsWin32: si una funcion no esta
// aqui, no se genera y el codigo no compila. Esta lista no puede desviarse de lo que el
// binario realmente usa, y por eso es el primer sitio donde mira un auditor.
//
// Cada grupo va bajo un comentario que dice para que es.

// --- Ventana propia (M0) ---

// --- Bucle de mensajes propio (M0) ---

// --- Consola para --check estando compilado como WinExe (M0) ---
AttachConsole

// --- El hook de teclado (M1). Ver SEGURIDAD.md §3.1 ---
// WH_KEYBOARD_LL NO carga ninguna DLL en ningun proceso ajeno: la doc dice que el
// callback "is called in the context of the thread that installed it", mandandole un
// mensaje a ese hilo. Es lo contrario de los hooks que si inyectan (WH_CBT,
// WH_GETMESSAGE, WH_SHELL), que siguen prohibidos por la regla 3.
//
// Solo se mira VK_SPACE. GetKeyState esta aqui unicamente para poder DEJAR PASAR
// Ctrl+Espacio, Alt+Espacio y Shift+Espacio, que son atajos de otros.
// GetAsyncKeyState no esta aqui y no va a estar: se puede consultar en cualquier
// momento sin que haya ocurrido ningun evento, y esa es justo la diferencia.
SetWindowsHookExW
UnhookWindowsHookEx
CallNextHookEx
KBDLLHOOKSTRUCT
WINDOWS_HOOK_ID
VIRTUAL_KEY
GetKeyState

// GetGUIThreadInfo es lo que impide que el programa se cruce con lo que el usuario
// escribe: si hay un cursor de texto parpadeando, la tecla pasa de largo.

GetClassNameW
GetWindowThreadProcessId
GetGUIThreadInfo
GUITHREADINFO
